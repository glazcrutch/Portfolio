FPGA Binary Counter

A binary counter designed in a hardware description language and implemented on an FPGA board, with the running count displayed on the board's LEDs.

Overview

This project turns a simple idea, counting in binary, into real hardware. Instead of running software on a processor, the counter is described as digital logic, synthesised, and loaded onto an FPGA so that the physical LEDs light up in the pattern of the current count.

What I built

  • A counter module described in a hardware description language
  • A clock-division stage so the count is slow enough to see
  • Pin constraints mapping count bits to the board's LEDs
  • Simulation of the design before programming the board

How it works

  1. The board clock drives a counter register.
  2. A divider slows the clock so each increment is visible.
  3. Each bit of the register is wired to one LED.
  4. The register wraps around to zero after its maximum value.

What I learned

Hardware thinks in parallel: every part of the design runs at the same time. I also learned why clock timing and testing in simulation first save a lot of debugging on the board.
