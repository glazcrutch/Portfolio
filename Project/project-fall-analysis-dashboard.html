Overview

Devices produce numbers, but numbers on their own are hard to act on. This project connects to the Nesso N1 and presents its live readings in a clean dashboard, so the current state of the device can be understood at a glance.

What I built

  • A web dashboard that shows live readings from the device
  • A layout that separates headline values from detail
  • Automatic refresh so the display stays current
  • A responsive design that works on phone and desktop

How it works

  1. The device produces sensor or status readings.
  2. The data is sent to the dashboard.
  3. TypeScript updates the page as new values arrive.
  4. The interface presents them as readable cards and indicators.

Skills & tools

  • TypeScript
  • CSS
  • IoT
  • Data visualisation
  • Next.js & Nest.js
  • Drizzle ORM

What I learned

Live data introduces problems a static page never has, such as missing or late readings. Designing for those cases, and presenting data simply, mattered as much as getting it to appear.
